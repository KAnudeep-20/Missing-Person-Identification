This folder is the reference database substitute (PROJECT_SPEC sections 11-12).

Create one folder per person. The folder name is the identity label used in
results (e.g. person_001). Put 2-5 photos of that person inside:

  - a frontal photograph
  - slight left / slight right pose
  - indoor / outdoor, different lighting
  - glasses / no glasses when relevant

Rules:
  - Never mix multiple unrelated people in one folder.
  - Only use photos you have consent and authorization to use.
  - No SQL tables, no extra files required - folders and images only.
